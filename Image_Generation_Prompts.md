## Technical Specifications

### Image Dimensions

**Reference Sheet (Three Views):**
- Midjourney: --ar 3:1 (3072x1024)
- DALL-E: 1024x1024 (will crop to 3:1)
- Stable Diffusion: 1536x512 or 2048x683

**Single View:**
- Midjourney: --ar 1:1 (1024x1024)
- DALL-E: 1024x1024
- Stable Diffusion: 768x768 or 1024x1024

### Pose Specifications

**A-Pose:**
- Arms slightly away from body
- Elbows bent at 90 degrees
- Palms facing forward
- Standing straight
- Feet shoulder-width apart

**T-Pose (Alternative):**
- Arms extended horizontally
- Palms facing down
- Standing straight
- Feet shoulder-width apart

## Prompt Combination Strategy

### For Best Results

1. **Start with main prompt** — Use the comprehensive reference sheet prompt
2. **Iterate with variations** — Adjust style modifiers for different looks
3. **Generate single views** — If three-view doesn't work well, generate each view separately
4. **Combine in post** — Use image editing to arrange single views into reference sheet
5. **Refine with details** — Add specific details in subsequent generations

### Iteration Process

1. Generate initial reference sheet
2. Review results
3. Identify missing details
4. Add specific modifiers for missing elements
5. Regenerate with refined prompt
6. Repeat until satisfied

## Tips for Best Results

### Midjourney
- Use `--style raw` for more control
- Use `--s` parameter for stylization (0-1000)
- Use `--ar` for aspect ratio
- Use `--v 6` for latest version
- Use `--no` to exclude unwanted elements

### DALL-E
- Be descriptive and specific
- Include technical terms
- Mention style explicitly
- Describe background clearly
- Include resolution if possible

### Stable Diffusion
- Use positive and negative prompts
- Adjust CFG scale (5-15)
- Use appropriate sampler
- Set appropriate steps (30-50)
- Use high resolution for detail
