## Tips for Best Results

1. **Consistency:** Use the same base prompt for all views, only changing the angle description
2. **Details:** Include specific rune patterns and armor details in each prompt
3. **Lighting:** Keep lighting consistent across all views (cinematic, volumetric)
4. **Background:** Use clean white background for easy extraction and modeling reference
5. **Resolution:** Specify 8K or high resolution for detailed texture reference
6. **Style:** Maintain "stylized realism" and "Unreal Engine 5" references for game-ready aesthetic
